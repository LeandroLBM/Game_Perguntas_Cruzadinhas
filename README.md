# Game Perguntas Cruzadinhas
# Como será feito o jogo?
O jogo será feito com base em um quiz. Entretanto, o usuário terá que selecionar alguns
itens para poder começar o quiz. Ex.: para responder perguntas relacionadas à CPU, o
usuário obrigatoriamente terá que clicar onde está localizado o processador na imagem de
uma placa-mãe. O jogo também terá um sistema de pontuação e vidas, além do aumento da
dificuldade de acordo com que as perguntas vão ficando mais específicas.
